# Instagram DM Bot

Автоматизация отправки личных сообщений (DM) в Instagram по списку профилей из CSV.  
Репозиторий: https://github.com/romanveselovski/instagram_bot

---

## Для AI-ассистента (Claude, Cursor и т.п.)

**Сначала запускается скрипт. Авторизация — только после того, как скрипт сам встанет на паузу.**

Правильный порядок на новом ПК:

1. Установить зависимости и подготовить `profile_links.csv` (см. ниже).
2. **Запустить** `python bot.py` (ассистент может сделать это сам).
3. Скрипт откроет Chrome и **сам перейдёт в режим ожидания** — рассылка ещё не началась.
4. Пока скрипт на паузе, **человек** в браузере:
   - вводит **свой** логин и пароль Instagram;
   - проходит капчу и 2FA, если Instagram их покажет;
   - убеждается, что вход выполнен (не страница `/accounts/login/`).
5. **Человек разрешает продолжение**: в терминале, где запущен скрипт, нажимает **Enter** — только тогда начнётся обработка профилей из CSV.

**Не храните логин и пароль в коде или в `.env`.**  
**Не нажимайте Enter за пользователя** — это явное разрешение продолжить после ручного входа.

Если поручили «запустить бот»: выполните шаг 2, сообщите пользователю, что скрипт на паузе и ждёт входа, и **дождитесь**, пока он сам нажмёт Enter после авторизации.

## Требования

- **Python 3.10+** (рекомендуется 3.11+)
- **Google Chrome** (актуальная версия)
- Аккаунт Instagram, с которого разрешена рассылка DM

## Установка

```bash
git clone https://github.com/romanveselovski/instagram_bot.git
cd instagram_bot

python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
# source .venv/bin/activate

pip install -r requirements.txt
```

ChromeDriver подбирается автоматически через Selenium Manager (отдельная установка не нужна).

## Подготовка списка профилей

Основной файл очереди: **`profile_links.csv`** (разделитель `;`, кодировка UTF-8).

### Формат (рекомендуемый)

```csv
name;city;address;website;instagram
Название;Город;Адрес;https://site.com/;https://www.instagram.com/username/
```

Скрипт берёт URL из колонки **`instagram`**.

### Старый формат

Одна колонка `Profile Links` с URL — тоже поддерживается.

### Собрать список из базы HoReCa

Если есть `horeca_italy_social.csv` с колонкой `instagram`:

```bash
python build_profile_links_from_horeca.py
```

### Очистить ссылки (убрать `?` и `#` в URL)

```bash
python clean_profile_links.py
```

Шаблон без данных: **`profile_links.example.csv`** — скопируйте в `profile_links.csv` и заполните.

## Запуск

```bash
python bot.py
```

### Порядок работы (важно)

| Шаг | Кто | Что происходит |
|-----|-----|----------------|
| 1 | Вы / ассистент | Запускаете `python bot.py` |
| 2 | Скрипт | Открывает Chrome, загружает очередь из CSV |
| 3 | Скрипт | **Становится на паузу** — открывает страницу входа Instagram и ждёт |
| 4 | Вы | В браузере входите в аккаунт (логин, пароль, капча, 2FA) |
| 5 | Вы | В терминале нажимаете **Enter** — **разрешаете** продолжить выполнение |
| 6 | Скрипт | Начинает рассылку DM по профилям из очереди |

До шага 5 автоматическая отправка сообщений **не выполняется**.

После обработки пакета:

- результаты допишутся в `profile_links_updated.csv` (колонка `status`);
- обработанные строки удалятся из `profile_links.csv`.

Повторные запуски снова начинаются с шага 1 (новая пауза на вход, если сессия в Chrome не сохранилась).

## Особенности и ограничения

| Особенность | Описание |
|-------------|----------|
| **Пауза после запуска** | Скрипт сначала стартует, затем сам ждёт; рассылка — только после Enter. |
| **Ручной вход** | Логин/пароль не в коде. Вход только человеком в браузере во время паузы. |
| **Капча и 2FA** | Решает только пользователь. Enter в терминале = разрешение продолжить. |
| **Пакетная обработка** | За один запуск — первые `BATCH_SIZE` строк (по умолчанию 20). |
| **Очередь** | Профили обрабатываются строго по одному, без параллелизма. |
| **Паузы** | После успешной отправки — случайная пауза 20–40 с (настраивается в `bot.py`). |
| **Ошибки** | Если кнопка «Сообщение» не найдена или не нажимается — переход к следующей ссылке **без** длинной паузы. |
| **Антибот** | Включены базовые меры (скрытие `navigator.webdriver`). Риск блокировки Instagram остаётся. |

## Настройки в `bot.py`

В начале файла блок `НАСТРОЙКИ`:

| Параметр | Назначение |
|----------|------------|
| `MESSAGE` | Текст сообщения |
| `BATCH_SIZE` | Сколько профилей за один запуск |
| `PAUSE_BETWEEN_CLIENTS_SEC_MIN/MAX` | Пауза после успешной отправки |
| `MESSAGE_BUTTON_TIMEOUT_SEC` | Сколько ждать кнопку «Сообщение» |

## Статусы в логе (`profile_links_updated.csv`)

- `Успешно отправлено` — сообщение отправлено
- `Кнопка сообщения не найдена` — закрытый профиль, блокировка или другой UI
- `Не удалось нажать кнопку сообщения` — элемент есть, клик не сработал
- `Ошибка: ...` — прочие сбои (поле ввода, таймаут и т.д.)

## Устранение неполадок

- **«Похоже, вы всё ещё на странице логина»** — войдите полностью и снова запустите скрипт. Может сохраниться `login_error.png`.
- **Chrome не стартует** — обновите Chrome; при необходимости: `pip install webdriver-manager`.
- **Пустой `profile_links.csv`** — добавьте строки или соберите из HoReCa.
- **Кнопка «Сообщение» не находится** — смените язык интерфейса Instagram или проверьте, что DM доступны для этого аккаунта.
